# Model request stream

`newnoa.rpc.ModelTransport/Exchange` is a gRPC bidirectional stream of the standard generated `google.protobuf.Any` message. The explicit schema is `exchange.proto`; envelope kinds and Go helpers are in `frames.go`. This avoids a second custom generated-message toolchain while retaining protobuf framing, HTTP/2 flow control, gRPC deadlines and cancellation. Compression is off by default.

Request order: `newnoa.rpc/request-head`, zero or more `newnoa.rpc/data`, `newnoa.rpc/request-end`, then client half-close. The head is bounded JSON `{method,path,rawQuery,headers,contentLength}`; `contentLength=-1` represents an unknown body length. Header maps preserve multiple values. Data payloads are raw bytes at most64KiB per message; metadata is at most16KiB and the hard request-body ceiling is32MiB. The existing model handler retains its tighter route-specific limits and authorization.

Response order: `newnoa.rpc/response-head`, data frames, `newnoa.rpc/response-end`, clean gRPC EOF. The response head contains `{status,headers,contentLength:-1}`; the end contains the HTTP trailer map. HTTP errors retain their original status/body. A handler abort or transport failure ends with non-OK gRPC status and never produces a clean response-end. Clients must propagate that failure, cancel the stream when their caller cancels or closes the response body, and must not replay inference over a fallback HTTP request.

The adapter streams through an unbuffered request pipe and synchronous bounded response sends. It does not collect a full response or run an unbounded queue. Only the existing model routes, private dispatch control and readiness/health are admitted; internal administrative routes, CONNECT and arbitrary URLs cannot be invoked through this service. Application authentication headers remain inside the existing API-authorized handler contract.

`http.ResponseController.SetWriteDeadline` remains effective on the adapter: a stalled send cancels the upstream request and returns `DeadlineExceeded` to the writer. With the shared `net/http` HTTP/2 listener, the native stream write deadline also aborts a blocked underlying write so the handler can exit. Go may reset that stalled HTTP/2 stream before gRPC trailers can be delivered, in which case the remote client observes a non-OK `Internal` transport error instead of `DeadlineExceeded`. Neither case is a successful response or permission to retry inference. Clearing a successful write deadline does not put a deadline on an idle upstream read.

The gateway multiplexes gRPC HTTP/2 requests with the existing HTTP/1 FRP WebSocket path and health handlers on its existing TLS port. API-authoritative transport/CA discovery and normal IP-SAN verification determine client trust; this package never disables TLS verification or distributes server secrets.
